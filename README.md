# Лабораторная работа №4. Вариант 12

## Назначение
Сравнение блокировки всего массива и отдельных записей на Windows SRW Lock.
В массиве 16 записей `SharedData { A, B, C, version }`. Инварианты:
`B = 2*A`, `C = 3*A`.

## Требования и реализация
- 3 читателя и 2 писателя по умолчанию.
- Два режима: `global` и `per-record`.
- Два распределения: `uniform` и `biased` (80% обращений к записям 0 и 1).
- SRW Lock в shared режиме для чтения и exclusive режиме для записи.
- События RUNNING, WAITING, ACQUIRED, RELEASED, FINISHED с PID/TID, ID участника, временем от старта и индексом ресурса в `data/events.csv`.
- Сбор статистики времени ожидания, времени выполнения, пропускной способности, числа операций, ошибок инвариантов и версий.
- Ограничение времени реализовано кооперативно: потоки проверяют общий deadline и прекращают новые операции. Вместо блокирующего Acquire используются TryAcquireSRWLock... с повторными попытками, поэтому ожидание ограничено тайм-аутом.
- Время `--work-us` моделирует работу между критическими секциями и не удерживает блокировку.
- CSV содержит одну строку на запуск. События пишутся в отдельный CSV.

## Сборка 
в Visual Studio

## Запуск вручную
build\LR4.exe --lock per-record --dist uniform --readers 3 --writers 2 --ops 200 --seed 11088 --timeout 30000

## Эксперименты
- `run_standard.bat`: 4 конфигурации x 3 повтора, 200 операций на поток.
- `run_experiments.bat`: 4 конфигурации x 3 повтора, индивидуально для ID=104: `SEED=11088`, `OPERATIONS=720`.
- Результаты сохраняются раздельно в `data/results_standard.csv` и `data/results_student104.csv`.
- События сохраняются в `data/events_standard.csv` и `data/events_student104.csv`.
- Скрипт `python py/plots.py data/results_student104.csv` строит два графика PNG рядом с CSV.

## Параметры варианта 12
`SEED = 1000 + 104*97 = 11088`.
`OPERATIONS = 200 + 104*5 = 720` операций на участника.
При 3 читателях и 2 писателях ожидается 2160 чтений и 1440 записей, всего 3600 операций за запуск.
